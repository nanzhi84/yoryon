# 静态分支

`codex/static` 将Web站点生成为纯文件，使用已有排版和URL，保留文章、帖子展开、公开合集目录/正倒序/上下篇/续读、标签、全文搜索和图片预览。登录、注册、账号、订阅、兑换、会员问答、通知、评论、点赞和转发模块已移除；静态快照及导出查询也不再携带评论或点赞数据。

原付费文章按照用户选择，仅保留现有匿名公开预览；隐藏正文不进入快照、搜索索引、HTML或浏览器数据。原私有OSS桶不改权限，媒体随静态产物提供。

合集只有在自身为公开且全部已发布成员均可免费阅读全文时才公开。含付费文章的合集整体隐藏：不生成目录，不输出文章中的合集关联、上下篇或站点地图记录。原有单篇文章的阅读范围保持不变。此规则同时用于内容导出和Web构建，旧快照直接构建也不能恢复隐藏合集。

## 构建和预览

仓库内 `content/site.json` 是可公开的内容快照，`content/media.json` 是站内媒体路径映射；`apps/web/public/media/` 保存媒体字节。已有快照可直接构建，无需数据库、API、OSS或其凭据：

```sh
pnpm typecheck
pnpm build
pnpm preview --port 3100
```

打开 `http://127.0.0.1:3100/`。预览只启动本机静态文件服务，不启动API。交付目录是 `apps/web/out/`，该目录可以交给支持目录索引的静态托管平台。`pnpm dev` 仅启动Web开发环境；正式验收使用上面的静态产物预览。

## 更新内容快照

执行 `pnpm static:export`。它直接只读连接内容数据库，不依赖阿里云服务器。凭据默认从本机受保护目录 `~/.config/yoryon-production/` 的 `secrets.json`（`database_api_url`）和 `oss-credentials.json`（只读API身份）读取；也可用 `YORYON_STATIC_CONFIG_DIR` 指定同样结构的受保护目录。不要把这些文件复制到仓库或公开产物中。

导出仅读取已发布内容；检查付费预览版本，过滤不允许公开的媒体。媒体下载最多3路并发、每个请求60秒超时、最多2次尝试，核对原始SHA256和尺寸后才提交。完整新内容先写入忽略的暂存目录，再替换导出工具管理的目录，移除不再使用的引用和媒体；失败时保留上一份完整快照。不要并行执行导出和构建。异常退出留下 `.local/static-export.lock` 时，确认没有导出进程后再删除该锁。

当前快照含64篇内容；原有37章合集包含22篇付费文章，因此整体隐藏。媒体清单见 `content/site.json`；当前内容没有音视频，播放器代码保留，但本次没有真实音视频可做播放验收。

## 运行边界

- 网页与媒体访问不连接Neon、原API或OSS，不采集并提交原数据库流量埋点。旧统计偏好工具及用户已有本地身份配置保持原样。
- 本地搜索只索引快照中允许阅读的文本，按连续字符串做字面匹配、不区分大小写，搜索状态在当前URL中。结果标题与摘要直接高亮命中文字；每篇只展示正文首处命中片段，遇到第二处命中即截断，省略处用省略号表示。无正文命中时使用描述命中片段，仅标题命中时显示原描述；标题保留完整文字。正文命中定位与高亮在浏览器完成。
- 合集续读使用当前浏览器本地存储，换浏览器或清理数据不会同步；存储不可用时正常浏览。
- 内容撤回/删除需要重新导出、构建和部署，并按所选托管平台的方式撤销旧部署；已经下载的公开文件无法收回。
- GitHub Actions只部署仓库内的公开快照，不修改生产数据库或原API/OSS。本地验收证据位于 `artifacts/static-20261028/`，设计见ADR-0018。

## GitHub Pages 发布与域名

工作流为 `.github/workflows/pages.yml`，推送 `codex/static` 后依次执行冻结依赖安装、`pnpm typecheck`、`pnpm build`、上传 `apps/web/out/` 和 Pages 部署。运行不需要数据库、OSS或阿里云凭据。生产域名为 `yoryon.com`，`www.yoryon.com` 跳转至主域名；Pages 设置使用 GitHub Actions 作为发布源。

DNS仅调整主域名与`www`：主域名的A记录指向 `185.199.108.153`、`185.199.109.153`、`185.199.110.153`、`185.199.111.153`，`www` CNAME指向 `nanzhi84.github.io`。保留邮件验证及其他子域名记录。Pages完成证书签发后启用强制HTTPS；变更后需实际验证域名解析、证书、正文、图片与浏览器交互。

更新内容时，先本地执行 `pnpm static:export`，检查公开边界与媒体，再提交快照和相关媒体并推送。回滚静态版本时，使用 `git revert <引入问题的提交>` 后推送，等待工作流完成并重新验收。DNS迁移前的主域名与`www`记录保存在本机发布工件中，恢复原动态站还需要原托管服务可用；本次部署不停止阿里云服务。
