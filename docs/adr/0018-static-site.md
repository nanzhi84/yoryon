# ADR-0018：静态分支与离线内容快照

日期：2026-10-28。分支：`codex/static`。

## 目标与边界

用户要求暂停常驻服务器成本，移除登录、注册、账号与订阅/兑换功能，保留原有公开内容、帖子、合集、标签、搜索、阅读导航与媒体体验，并提供本地预览。用户明确选择原付费内容继续只显示原有公开预览，不能公开隐藏正文或付费媒体。

## 数据流与职责

1. 导出工具只读查询内容库，仅导出已发布内容、当前匿名预览、公开目录及公开评论展示信息；不导出账号、认证、权益、分析事件或密钥。校验预览版本与引用边界，不可确认的内容停止导出。
2. 只下载导出正文/封面/公开引用实际允许访问的媒体，校验内容寻址哈希及尺寸，存为站内静态文件，不使用签名链接或OSS运行时回源。请求有超时、有界重试、并发限制；下载不完整时不发布快照。
3. Next.js 在构建时消费经过校验的本地快照，使用 `output: export` 生成独立文件。浏览器只使用静态文件和可选本地存储；搜索、帖子展开、分页、合集章节上下篇与续读在浏览器完成。
4. 删除旧Web端BFF、运行时权限门禁、登录/订阅路由和相关组件，不能用空API或旧接口兼容层伪装静态化。API/CLI原项目作为独立历史内容管理工具保留在仓库，不参与静态Web运行。

## 保留功能的静态语义

- 公共文章、帖子、标签、合集、作品引用、SEO与原有URL保持可访问。
- 原付费内容仅输出匿名预览，使用普通预览说明，不再提供订阅、价格或兑换入口。
- 搜索在本地索引中检索已导出的可见文本，支持命中跳转；不得将隐藏正文作为索引输入。
- 已有公开评论与点赞数量保留为只读。新增评论、登录态点赞和通知依赖服务端，本分支不提供；分享复制链接保留。
- 图片/音视频尽量随静态产物提供；超出未来托管平台单文件限制时单列实际大小，本地预览仍保留媒体，不擅自删除媒体或开放原私有桶。

## 验收与发布

执行项目 `pnpm typecheck` 与 `pnpm build`；随后由独立agent使用普通静态文件服务浏览真实内容，核对功能、失败与边界、媒体字节、无运行时API/Neon/OSS请求、无非公开内容及密钥。现场命令与回执放入 `artifacts/static-20261028/`，不新增固定测试程序。

用户在本地验收后明确要求提交推送静态分支、发布GitHub Pages并迁移 `yoryon.com`。GitHub Actions仅从本分支构建公开快照，部署目录为 `apps/web/out/`；运行不读取生产凭据或数据库。先在Pages绑定域名，再调整主域名与`www` DNS，证书可用后强制HTTPS，并独立验收公网真实路径。

原动态站的已提交版本保留在原分支，数据无需迁移或双写。静态版本通过revert提交重新部署回滚；DNS回滚使用本机发布工件中的原记录，原托管服务必须恢复可用。该发布不停止或删除阿里云、Neon或OSS资源。
