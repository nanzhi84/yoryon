# ADR-0015：精确字符搜索、权限与滚动额度

状态：实施（Issue #23）。

## 边界与数据流

CLI publish → Markdown/remark-rehype → 渲染文本及 UTF-16 节点映射 → 同事务 search_projections。
Next.js 弹窗 → POST BFF → Hono → PostgreSQL 候选过滤/精确匹配 → 当页 canAccessMany 裁剪 → 浏览器结果。
详情 fragment 中仅携带搜索会话、revision、起始位置；POST locate 重新授权后返回节点范围，CSS Highlights 高亮，不重写原文 DOM。

共享 `config/search-text` 只含浏览器安全的渲染文本协议；core 负责解析和维护派生投影；API 负责授权、额度和会话；web 不实现授权，也不下载全文进行搜索。Shiki 在节点映射之后处理，保持相同文字和节点身份。正文普通文本显式使用 white-space:pre-wrap，保留连续空格与软换行为可见原文，代码块继承原有白空格规则；结构块边界使用换行；图片替代文本、原始 HTML、媒体及嵌入作品内容不参与。

## 匹配与有界工作

严格连续、大小写敏感的 LIKE（转义 `%`、`_`、反斜线），GIN pg_trgm 过滤，strpos 排序。标题优先、描述其次、正文最后，同级发布时间 DESC NULLS LAST、UUID DESC。查询 1–120 UTF-16 码元；只有含三个连续 Unicode 文字或数字的查询搜索正文，其余仅标题/描述，UI 明示。标点仍参与精确匹配，不删除或规范化。

先在数据库限制 1001 个候选，再对 ≤1000 个排序；超过 1000 返回范围过大，不扣额度，不伪装完整结果。只加载当页最多20篇正文计算前三处上下文，原文定位每次最多100处，通过 after 继续。SQL statement_timeout 1500ms，lock_timeout 1000ms；API 全文查询最多4个并发，网络每分钟40次请求保护；原文定位每分钟60次。限流不等于产品额度。

## 权益与额度

正文访问复用 canAccess / canAccessMany，包括历史单篇与合集权益；无限搜索只认有效 subscription 或管理员。免费用户付费正文结果无上下文、位置、版本、命中数量或正文命中字段。公开标题与描述可由浏览器高亮。

PostgreSQL 搜索会话同时作为成功受理的滚动60分钟账本：同一用户稳定 ID 或 HMAC 签名匿名 UUID；所有非订阅请求还受同一可信网络哈希的10次限制。先固定顺序取得事务 advisory locks，再核对额度，查候选、保存会话与生成结果在同事务提交；失败回滚不扣次。共享网络采用保守限制，可能影响同一 NAT 下多个免费用户，属于防绕过与易用性的明确取舍。订阅无产品额度，仍有限流保护。

requestId 幂等绑定身份及查询 HMAC；相同请求的重放返回原会话，不是新搜索。分页仅接受服务器会话与固定20篇位置，不能另传词。每页重新核查权益。额度释放由服务器时钟计算，返回剩余次数及释放时间；额度耗尽时不执行全文候选查询。

查询不进入 URL、分析、SQL错误日志；只在60分钟会话中 AES-256-GCM 加密保存以支持跨实例分页和定位。网络、身份、查询索引均是带服务端密钥 HMAC，响应不暴露这些标识。每次全新请求增量清理最多100个过期会话，管理员 CLI `search prune` 删除全部过期会话，部署定时运行，避免过期加密数据持续存留。

## 一致性、迁移与回滚

数据库触发器在正文/标题/描述变更或下架时删除旧投影并推进 epoch；纯缓存刷新、合集或嵌入作品失效引起的 revision 轮换，同事务携带原文本映射至新 revision，不索引嵌入正文；下架/删除实时过滤。publish 在同事务内重新建立当前 revision 投影。直接 SQL 改写正文/标题/描述导致搜索失败关闭，需 `search rebuild` 修复。游标/定位绑定 epoch 与内容 revision，任何内容更新使旧会话失效，不对旧位置静默重定位。

部署运行 `pnpm db:migrate`，在发布锁内回填公开预览后补齐搜索投影。CLI `pnpm cli search rebuild` 按每批100行加行锁，可重复生成，不改正文与权益；完成后清理 GIN pending list 并刷新 planner statistics。空库先迁移再发布。pg_trgm 扩展需数据库部署账号有创建权限。

回滚应用可保留新增表与触发器；旧发布器不会维护新投影，重新启用新版本前必须 rebuild。不能删除旧正文或权益。性能结论以隔离数据集的实际 EXPLAIN/P95 工件为准，300ms 是验收目标，不是生产保证。
