# ADR-0014：帖子、长文与作品引用

状态：实施中；验收范围记录在对应 PR 工件中。

## 目标与边界

作品的阅读形态只有 `post` 和 `article`，媒体仍是 Markdown 中的内容块。长文要求标题；帖子标题可空，slug 仍必须由作者指定，页面名称回退为正文摘要或发布时间。CLI 是唯一作者发布入口，因此所有站内作品均属于同一创作者，不增加多作者管理界面。

文字、图片、`::video{src="..."}`、`::audio{src="..."}` 与 `::work{id="作品 UUID"}` 按原顺序呈现。发布事务校验引用目标已发布、存在并非自身，最多 20 个不同目标。引用关系保存 UUID，删除目标后保留原 UUID 和不可用占位；不复制旧正文。

引用卡片通过独立 no-store 端点读取当前公开投影，摘要最多 280 个字符，不递归呈现媒体指令或引用卡片。允许不同作品形成循环关系，读取始终只有一跳；禁止自引用。引用付费作品不会扩展权益。目标变化时同事务更新直接引用者 revision 并写入缓存事件（最多 100 个直接引用者，超限拒绝提交并提示拆分处理），覆盖详情、首页、标签和合集。间接引用不复制后代摘要，因此不需要递归失效。

## 首页与权限

首页和订阅分区遵循 ADR/Issue #15。帖子初始显示最多 900 权重、6 个顶层块，图片/视频/音频/引用每块计 300；文本按源码字符权重，边界文本在 AST 内截断。浏览器展示高度最多 32rem，展开后高度不限。展开读取现有私有 no-store 详情接口，由 API 决定当前权益；收起卸载展开正文。长文只显示标题、摘要、封面，不提供原地展开。

公开 Feed 仅包括经过权益裁剪后再折叠的帖子正文及其中可见媒体元信息。不能先折叠全文再裁剪付费预览。图片延迟加载，可单独查看；播放器仅在点击播放后挂载，停止、离开视口、收起与卸载释放资源，同一页面只激活一个播放器。展开、收起、查看图片、播放不记为详情 Click/View/Read；明确的详情链接沿用原统计合同。

## 迁移与失败方式

现有 article 保持不变；image/video/audio 改为 post。迁移先保存受影响行的原类型、正文、revision 与更新时间到专用恢复表，再将原主媒体补成正文开头的媒体块（已出现则不重复），其余正文顺序不变。保留 ID、slug、发布时间、媒体 exposure、标签、合集、置顶和统计。迁移后生成新 revision 和目录缓存事件，停止发布并备份后执行；回滚前先部署兼容旧类型的版本并按恢复表还原，停写期间检查行数、主媒体和权限，随后重新失效缓存。

- 非法引用、自引用、目标草稿：发布事务失败，原已发布版本保留；上传孤儿由现有 GC 处理。
- 引用目标下架或删除：显示不可用，不删除引用者评论。
- 目标权限收紧：新读取只返回当前公开摘要，旧 revision 门禁失败关闭。
- 展开请求错误或取消：保留折叠正文，提供重试；旧请求不得覆盖后来作品。
- 单条媒体失败：局部错误反馈和重试，不能触发整卡导航。
- 不维护固定测试套件；由独立子代理现场验收迁移、发布、权益、引用、浏览器和媒体字节，记录未覆盖项。
