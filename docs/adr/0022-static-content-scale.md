# ADR-0022：纯静态内容规模与有界页面数据

状态：已实现，2026-11-01。本地验收见 `artifacts/static-scale-20261101/`；发布版本、工作流与线上验收回执见 `artifacts/static-scale-release-20261101/`。

后续交互修订：[ADR-0023](0023-static-infinite-scroll.md) 保留这里的数据分块与静态深链，将可见分页改成无限滚动、近底部预取及远处块卸载。下述分页 URL 仍有效，正常浏览不再要求点击下一页。

## 目标与边界

合集点击原先依次等待 RSC 和客户端 Markdown 渲染代码；全量目录、搜索正文、媒体映射与每页重复内联脚本又会随篇数增长。保留纯静态托管、现有公开内容范围、功能与原有 URL，使普通浏览只依赖当前页的数据。全文检索和全站构建保留必要的全量工作。

本决策取代 ADR-0020 `static-script-packing` 的脚本内联方案，以及静态加载方案中的 CSS 内联。历史实验仍保留为证据。

## 数据流与职责

1. 导出工具继续只读源数据、投影匿名公开内容；媒体、标签、合集成员按外键一次分组，替代逐内容过滤整表。
2. `packages/config/src/static-catalog.ts` 校验快照、隐藏不满足公开条件的合集、移除相应内容关联，并构建 slug、标签、媒体索引。每个构建 worker 内复用一次解析与排序；文件替换后失效，开发时不永远缓存旧快照。
3. Web 路由在构建阶段查索引并切片。浏览器只接收当前页、当前正文、当前媒体 URL；不导入快照或全站媒体表。公开预览继续是唯一可进入构建的付费内容。
4. `prepare-static-data.ts` 从同一份公开目录生成版本化 JSON。暂存生成完成后替换生成目录；锁防止两个数据生成进程同时提交。构建与导出不要并行。异常退出后，确认无进程再移除 `.local/static-data.lock`。
5. 输出仍只有 HTML、RSC、JS、CSS、JSON 和媒体文件。没有运行时数据库、API、SSR 服务或搜索后端。

## 分页与 URL

普通列表及目录每页 12 条，搜索每页 20 条。先切片再生成视图模型、正文与结构化数据，不在客户端持有全量列表后仅隐藏 DOM。

| 入口 | 原有第一页 | 新增后续页 |
| --- | --- | --- |
| 首页 | `/` | `/page/2/` |
| 帖子 | `/posts/` | `/posts/page/2/` |
| 合集列表 | `/c/` | `/c/page/2/` |
| 合集目录 | `/c/<slug>/` | `/c/<slug>/page/2/` |
| 合集倒序 | 原来在目录内切换 | `/c/<slug>/reverse/`、`/c/<slug>/reverse/page/2/` |
| 标签列表 | `/tags/`；`/explore/` 保留 | `/tags/page/2/` |
| 标签内容 | `/tags/<slug>/` | `/tags/<slug>/page/2/` |
| 搜索 | `/search/?q=...` | `/search/?q=...&page=2` |

文章 `/p/<slug>/`、搜索词、合集上下文 query 参数、媒体路径和旧公开引用数据路径均保留。无效/越界静态页为 404。首页与帖子 `/page/1/` 别名 canonical 回原入口，用于兼容 Next 静态动态段在没有第二页时的构建限制。站点地图只列正式正序分页路径，不重复收录倒序。

倒序只反转当前窗口，序号由总数和偏移计算，删除 `indexOf` 带来的平方扫描。合集描述作为服务端渲染插槽传入，不让交互组件引入 Markdown 引擎。

合集继续读使用原有 `version: 1` localStorage 记录。记录在当前页时直接恢复；在其他页时按集合 ID、章节 ID 读取单个 JSON，并计算该章节在正/倒序中的页码。不存在的章节清除旧记录，网络失败显示重试；存储不可用仍可正常阅读。请求有取消、15 秒超时和过期响应隔离。手动重试使用 `cache: reload`，避免重复命中缓存的失败响应。

## 共享资源与预取

Next 的哈希 JS/CSS 保持独立文件，可在多个页面间复用 HTTP 缓存；删除全站脚本内联后处理器，不再把整站产物一起读入内存重新打包。Tailwind 只扫描 app、components、lib，避免公开 JSON、内容文本或验收工件扩张样式表。

合集入口、当前可见目录项及相邻分页启用 Next 可见区域预取。分页限制了可预取项的数量；它仍会增加用户未必打开的公开文本流量。媒体不提前整批下载。预取失败时保留原静态 URL 导航回退；既有 Next 补丁继续适用。预取未完成时不承诺瞬时打开。

## 分片全文搜索

- 构建时按约 64 KiB 目标分片；单篇长文保持完整，避免截断跨块字符串。64 个字词索引桶保存单字符/双字符到分片的倒排关系。
- 查询选择至多三个锚点求候选分片交集，再用原有转义后的 `/iu` 连续字符串匹配确认。不是分词搜索，不改变中文连续匹配、标点、大小写或正文首处命中摘要规则。
- Unicode 大小写不能安全用于剪枝的查询保守扫描全部分片，避免漏结果；ASCII 对应的 long-s/Kelvin 简单折叠另行处理。正文定位也使用相同字面正则语义。
- Worker 最多三路读取，单请求 15 秒超时；换词取消旧请求并忽略过期结果。主线程只接收当前 20 条结果。查询结果顺序仍按快照内容顺序；结果翻页复用上一查询。
- 解析数据缓存以源 JSON 的 UTF-16 字节估值计账，LRU 预算 8 MiB。它不包含对象开销及当前结果集，**不是整个 Worker 堆内存上限**。
- 手动重试重建 Worker 并绕过 HTTP 失败缓存。加载、空查询、无命中、错误均有可见状态；没有后台无界重试。
- HTML 和 JSON 使用快照哈希绑定版本。旧页面遇到已替换版本的数据时可能需要刷新；撤回公开内容仍必须重新导出、构建与部署，已下载的文件无法收回。

## 复杂度与容量

令 N 为篇数、E 为标签/合集/媒体关联规模、B 为文本字节数，P 为固定页长。

| 阶段 | 成本与限制 |
| --- | --- |
| 构建目录 | 解析/校验 O(B + E)，内容排序 O(N log N)，标签目录另有排序成本；Map 查询期望 O(1) |
| 导出关联 | 一次分组 O(N + E)，不再逐篇扫全表 |
| 浏览列表/目录 | O(P)，P=12；相对全站 N 有界，实际仍取决于当前页正文/描述/媒体大小 |
| 单篇阅读 | 只处理本篇正文及关联；正文再长也不是 O(1) |
| 续读定位 | 一条记录、至多一个章节 JSON，与合集总章数无关 |
| 搜索 | 剪枝减少常见查询的 I/O；最坏 O(B)，结果内存 O(命中数)，页面 DOM 为 O(20) |
| 全站输出 | 随正文与关联规模增长；生成全站不可能为 O(1) |

本地使用 3000 篇真实内容（现有 68 篇 + 2932 篇 MDN 原文）构建，并在真实浏览器验收 2932 章目录、末页、倒序、跨页续读与搜索。构建耗时、内存、资源大小和已知限制以本次工件为准，不据一次构建承诺公网 SLA。纯静态托管仍受站点体积、图片视频体积、构建机器内存及托管平台容量约束；增加内容不需要恢复业务后端。

## 回滚与未覆盖项

本次未改变持久化快照 schema、既有公开 URL 或 localStorage schema。可回退此实现并重新构建全部产物；不需要数据库迁移。分页是新增 URL，若发布后回退旧实现，这些新增 URL 将失效，需要单独评估外部链接。

验收不使用合成内容或固定断言套件；文档来源、隔离数据、命令及实际浏览器回执位于工件目录。未测真实音视频、真实引用卡片（当前快照无这些内容）、真实手机及公网发布后行为，不把静态检查或 HTTP 200 作为这些业务通过的证据。
