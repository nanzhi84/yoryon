# ADR-0023：静态分块与无限滚动

状态：已实现，2026-11-01。用户要求恢复无限下滑；ADR-0022 的数据分块继续使用，可见分页不再作为正常浏览交互。

## 目标、边界与数据流

- 首页、帖子、标签、合集列表及目录、搜索结果接近底部时自动追加；原有入口和已发布的分页深链继续可访问。分块是传输边界，不要求读者点下一页。
- 构建端从同一公开快照生成版本化列表 JSON，每块 12 条；首块随静态 HTML 渲染。帖子与合集描述在构建时转成受限的展示节点，浏览器只渲染节点和现有媒体交互，不重新解析 Markdown、不携带全站媒体表。
- 视图模块只读当前块；读取模块负责校验、取消、超时、有限并发、8 MiB JSON 估算缓存和失败重试。接近底部最多预取一块，进入加载区域后追加，避免递归预取整站。
- 预取距离为视口外 1200px，追加距离为 400px；开启省流量时跳过提前预取。可见窗口额外保留上下各 1600px；焦点所在块暂不卸载。缓存预算不包含 React 对象、当前活跃块和运行时开销，不是整个浏览器堆的硬上限。
- 已经过的远处块以测量高度保留位置、卸载可交互 DOM；回滚时按需恢复。会话记忆只保存已到达的块号、宽度和高度，不复制全站内容。浏览器返回先恢复列表占位高度，再由原有导航记忆恢复位置。
- 搜索保留 Worker 中的连续字面匹配、取消与分片索引，只改变结果展示为按块追加。新的查询清空旧列表；后续块失败保留已展示结果。
- 无 JS 时保留普通静态后续链接；加载失败给出重试和静态链接回退。没有运行时 API、数据库或动态服务。

## 失败边界与复杂度

验收前明确：近底部请求去重、尾块不足、快速切路由/排序/搜索不串数据；错误缓存后的重试真正重读；后续帖子展开/图片预览仍可用；返回时不能先滚到错误位置；旧深链与续读仍能定位。使用原有公开内容和此前隔离的真实 MDN 语料，不增加固定测试程序或合成内容。

首屏和每次追加为 O(P)，相对全站 N 有界；远处块不持续保留 DOM。已访问块的高度元数据为 O(访问块数)，缓存有预算，单篇仍受正文大小影响。搜索最坏 O(B)，生成全站仍随内容增长。无限滚动不意味着完整阅读全站的总成本为 O(1)。

实现、真实浏览器证据、运行命令和未覆盖范围保留在 `artifacts/static-infinite-20261101/`。沿用原 URL、公开内容投影和续读 schema，不需要数据迁移。

视口预加载依据 [Intersection Observer 的 rootMargin](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API)。列表展示节点复用当前锁定版本 react-markdown 的同步转换及现有 Markdown 插件，节点只允许有限标签、属性与样式；不把外部 JSON 当任意 HTML 注入。
