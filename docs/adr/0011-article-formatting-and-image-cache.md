# 中文正文与公开图片缓存

业务目标：中文加粗和行内代码与作者的 Markdown 一致，图片缩小传输体积，重复阅读复用 Vercel 字节缓存。

失败方式与边界（实现前）：

- 中文标点旁的 `**` 被 CommonMark 误当文字；发布序列化转义后网页插件无法补救。发布、预览和网页须采用相同 CJK 规则；转义文字和代码不变。
- Typography 的代码伪元素增加可见反引号；移除装饰，保留语义 code 和块缩进。
- 每次签名跳转地址变化使浏览器重新加载；只缩放 PNG 未减少格式开销。
- 无门禁的 CDN 或浏览器长期缓存会在公开转付费/下架后继续分发。门禁不可依赖旧正文、会话或缓存失效事件的顺序。
- 任意 width/quality/query 可制造无限缓存键；只接受四档宽度和原始 SVG，压缩规则版本写在路径中。
- 故障时不得回退到旧公开权限；请求有截止时间，错误响应 no-store，原图与付费媒体保留原链路。

数据流：发布事务提交 → 持久事件刷新单进程 API 的公开策略快照 → Edge 每次读取当前图片公开策略 → Vercel 缓存不可变图片字节。冷请求通过无身份 API 读取私有 OSS 的签名变体，字节由 Vercel 缓存；签名 URL 不进入公开 HTML。PNG/JPEG/WebP 缩放并转质量 72 的 WebP；SVG 保留矢量与文本。

公开策略严格复用媒体的现有免费语义：已发布内容封面、合集封面、已发布内容 exposure=free。快照在同一个只读 repeatable-read 事务重建；请求只读内存，多实例部署前需改为共享强一致门禁。

浏览器 `max-age=0, must-revalidate`，在门禁之后以 ETag 返回 304，避免重复传字节；Vercel `s-maxage=86400`。暖缓存也先验当前权限，旧 URL 与条件请求均不能绕过。客户端已取得的副本无法远程召回。

图片冷缓存填充函数放在 sin1，与现有 API/OSS 同区；只在冷请求读取源站，后续字节由 CDN 服务。SVG 的 CSP 允许其内部样式，但禁用脚本、外部资源和同源权限。

验收：独立发布/浏览器 E2E 验证中文格式、代码保真、WebP 实际像素、宽度白名单、ETag、公开转付费/下架；生产另查真实 OSS 变体字节、CDN HIT、重复页面浏览器网络及三个真实文章。日期移除仅作用于博客稿，写作日期元数据和 Notion 原文保留。

回滚：恢复上一个 API image 和 Vercel deployment；正文可用保留的博客稿重新发布。原图不覆盖，不增加数据库迁移。
