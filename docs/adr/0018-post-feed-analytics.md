# ADR-0018：帖子信息流曝光与有效阅读

状态：已接受（2026-10-15，用户确认）

## 目标与边界

帖子在信息流直接消费，不应依赖详情点击判断阅读。帖子只保留曝光与有效阅读；不新增展开事件，点赞评论直接使用业务记录。文章和合集沿用现有口径。不扩大首页之外的采集表面。

## 决策与数据流

- 首页列表实例为统计边界：帖子曝光沿用可视面积≥50%连续1秒；有效阅读为同一实例内可视面积≥50%累计前台5秒，滚出视口或切后台暂停。主动成功展开正文立即记同一个read，自动恢复展开、失败请求不算主动展开。
- PostAnalytics拥有可见计时和唯一read回调；PostEntry仅在实际主动展开成功后调用。计时、收起后再展开、effect重放均复用列表实例＋帖子ID去重键。不为每条帖子发起新的读取请求，不记录展开原因或额外身份。
- 沿用事件队列→BFF→ingest→analytics_events→CLI。帖子read携带placement=home_feed以区分历史详情read；现有text列允许此值，无需DDL。API按已发布作品实际type过滤，帖子只接受impression/read且来源home_feed；旧帖子click/view/read(NULL)被丢弃。文章及合集的read仍为NULL。
- 帖子详情不挂作品详情View/Read；帖子日期和评论入口仅导航。不改变正文权限判断、付费预览、互动和合集的授权章节流程累计。付费卡片的五秒表示读了当前展示内容，不表示已获得全文权限。
- CLI按帖子/文章/合集分别汇总，帖子read_rate=reads/impressions，click/view/ctr为N/A；click/view/ctr排行不纳入帖子。查询保留原始历史事件，但剔除当前帖子旧详情指标，不回填或改写旧数据。已删除作品类型不可知，总览单列deleted-work，保持旧数据而不猜测。

## 故障与限制

沿用DNT/GPC完全拒绝采集、Cookie缺省降级、event_id去重及一次有界重试；采集故障不阻塞阅读。计时与Observer在卸载时释放。卡片高度超过视口两倍时50%阈值不可达，除非主动展开否则不会满足阅读；这是严格面积定义的边界，不偷偷改变阈值。帖子Read是可见停留或主动展开，不代表完读。展开很快时read可能早于1秒曝光，阅读率可能超过100%，不补造曝光或封顶。

切换前后阅读口径不能直接比较；旧网页仍打开时旧帖子详情事件将被过滤。回滚应用可忽略新read来源，数据库历史原样保留；若以后恢复旧CLI，其NULL假设必须先适配，不能把新帖子read当详情read。

验收须从真实首页检查不足5秒、累计跨滚出/恢复、展开即时及去重、失败展开、文章原口径、帖子详情不采集、非首页不扩大、API类型及来源过滤、CLI历史隔离。实际命令与证据保留在artifacts/post-analytics-20261015/，不新增固定测试程序。
