# ADR-0012 会员问答和展示资料边界

状态：实施中，Issue #15。问答是独立实体，以 users 和自然月为额度主键；讨论复用 comments 的交互事务，以显式 question_id 外键关联。作品与问答权限分开判定。

公开问答问题可读，回答只允许有效 subscription、提问者本人和管理员。本人历史回答不因订阅过期消失。私密与隐藏问答只对本人/管理员可见，关闭其他会员讨论。问答端点和网页始终 no-store，不进入静态文章、公开图片、公共CDN缓存。通知仅保留事件与经权限核对的链接，不保存回答预览。

display_name 与 username 分离，历史互动联查当前用户资料。头像认证上传，经 sharp 解码并重编码为 WebP，拒绝外站 URL、SVG、动画、不匹配MIME和超过2MB/1600万像素的图片。对象以内容hash置于 avatars/，upload与GC共享 advisory lock，GC保留当前头像引用并清理失效引用。

部署需将 API OSS 身份从只读 media/* 扩展为只读 media/*、读写 avatars/*；CLI GC 身份需读/列举/删除 avatars/*。不得给 API media/* 的发布写入权限。未调整身份的部署仍可读取资料，但头像上传会失败；用隔离存储完成接受后再验证目标环境，不能以构建通过视为上传通过。

首页仅免费，订阅仅付费元数据，作品正文仍走既有 canAccess 与公开预览隔离。单个首页置顶由CLI更新并沿用发布互斥和缓存事件；合集 visibility 是目录标记，目录本身可发现，作品各自判定权限。

回滚：先回滚 API/Web/CLI 到旧版本后保留新增表/列；无需破坏会员问题或历史资料。禁止删除新数据作为代码回滚手段。
