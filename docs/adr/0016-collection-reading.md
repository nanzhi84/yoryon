# ADR-0016：合集入口、独立首页展示与连续阅读上下文

状态：接受。关联：[Issue #26](https://github.com/nanzhi84/yoryon/issues/26)。

## 目标与边界

日更合集按合集进入信息流，并按稳定章节顺序连续阅读；单篇首页展示与会员权限分别管理。合集是独立统计对象，沿用 `targetKind=collection`，保持 contents / collections 各自领域，不增加合集评论、点赞、分享或购买模型。

## 持久化与发布

- `contents.show_in_home` 是作品唯一首页设置。迁移把既有免费作品设为 true、会员作品设为 false，保留原首页 public-only 的可见状态；既有免费合集章节也保留展示，不批量隐藏。首次独立发布 true，首次合集内发布 false。frontmatter `show_in_home` 显式值优先；缺省的重复发布读取既有数据库值。CLI `content home/hide` 修改该值并发布缓存事件。
- 首页读取 published + show_in_home；会员项通过原匿名 preview 派生函数呈现，正文与媒体仍由既有权益模块校验。订阅页的 paid-feed 维持原语义。
- `collections.is_pinned` 支持多个置顶；列表全序为 is_pinned desc、updated_at desc、id asc。合集自身资料/封面/置顶变更与章节新增、修改、撤回、删除均更新 updated_at。多合集章节同时刷新原与新归属。
- 发布过程持有现有 publish/GC advisory lock，成员变更前再按合集 ID 锁定合集行。保留既有成员 sort_order，新成员取当前末尾 + 1；编辑不改变顺序，显式 sort 按现有顺序保留未列出的成员。目录与邻接统一按 (sort_order, content ID) 排序，兼容既有同序号数据。撤回后目录不再包含该成员。
- 资料修改/章节排序失效合集页及相关单篇页；缓存事件按最多 90 个章节切分，满足既有事件 100-target 上限。写入与缓存事件同事务；页面门禁仍依据实时数据库版本，投递失败保持有界重试。

## 封面媒体生命周期

`collection cover` 持有同一媒体锁，读取图片、计算内容寻址 key、上传并去重，然后事务 upsert media_assets、更新 cover_media_id / updated_at 与缓存事件。内容发布与合集封面共用媒体准备、上传重试和元数据写入实现。不会把图片字节或签名 URL 写进数据库；上传与关联失败保留原封面。

`/api/media/:id` 已允许任意合集封面匿名访问，并只返回短期签名 URL，桶保持私有。封面公开是作者的主动关联；不改变其他会员正文媒体的 exposure。引用计数即时查询内容媒体边、作品封面、合集封面与头像；更换/清除仅撤销关联，GC 依旧复核引用与宽限期，不立即删除共享对象。

## API 与权限

- GET `/api/collections` 返回公开介绍、封面元数据、最新更新时间、置顶、已发布数量。
- GET `/api/collections/:slug` 返回介绍和带稳定章节 ID 的已发布目录；目录公开可发现，个体权益判断只返回 full/preview 并使用 private,no-store，不返回正文。
- GET `/api/collections/:slug/chapters/:contentId` 返回 canonical 合集、当前章节和相邻已发布章节的元数据；无效 ID、移除/撤回章节与错误合集均 404。只校验统计和导航的成员上下文，不能作为权限凭证；正文接口继续逐篇实时校验权益。
- 内容详情的所属合集与相邻章节返回稳定 ID。无有效上下文的作品直达，不通过自动归属推断本次合集阅读流程。

## 浏览器续读与统计约束

前端以稳定合集 ID 持久化仅含版本、章节 ID 与时间的本地定位，当前目录和上述成员接口共同验证。仅前台实际展示有权限正文后写入；预取、SSR、未解锁预览、错误及加载不写入。会员到期保留定位但继续提示解锁，失效成员清除定位；存储异常降级为开始阅读。多个合集按实际上下文分别记忆，多标签页监听 storage 同步。

每次独立进入合集详情建立流程；章节入口、上下篇与返回目录沿用该流程。合集介绍/目录前台停留和有权章节正文前台停留累计 10 秒记录一次合集 Read；刷新或离开链路后重新进入不能拼接。目录再次展示可以产生新的合集 View，但章节本身的 View/Read 仍归作品，不增加合集 View。Read 是流程停留指标，不代表读完或由章节 Read 求和。曝光/点击只来自合集列表真实可视/主动入口；续读与章节入口不产生合集 Click。

匿名 visitor_id 与留存指标由 Issue #27 管理，本变更继续沿用现有采集、隐私控制、event_id 幂等及有界重试协议。服务端上下文成员校验与权益校验均不能被 localStorage 的 URL/权限替代。

## 回滚与验收

迁移只添加字段并初始化集合真实更新时间，回滚应用版本可忽略新字段；不删除媒体或原章节关系。独立隔离验收需覆盖发布默认/显式值、迁移存量、并发追加、旧新合集更新、媒体字节与共享引用、失败保留、缓存、目录与邻接、免费/会员授权及浏览器续读/流程统计。验收工件写入 artifacts；静态检查或 HTTP 成功只证明相应技术步骤。
