# 独立验收边界（实现完成前）

目标：用户点击文章标题后，当前路由进入独立 /p 页面，在正文等待期间显示页内骨架；首页不出现“正在打开…”。

失败方式：
- policy middleware 或 metadata 等待导致骨架也被阻塞，主页仍滞留。
- 自动预取实际带全文，付费变更后客户端旧全文被复用。
- error/404 在 stream 开始后只抛服务端错误，骨架永久保留或缺少重试。
- 返回首页丢失内容列表/位置，点击后文章仍插入信息流。
- 首次冷导航没有预取时可能需要一次网络往返；不能把已预取页面单次观察描述成任意网络绝对零延迟。

验收选取实际首页文章；权限撤销使用独立 slug，仅在隔离 preview 数据库发布自己的临时内容并最终清理。不修改已有公开稿，不触碰生产。浏览器只用本 agent 新建 IAB 标签。

状态评估分开记录 DOM、URL、RSC 负载、Cache-Control 和绘制：DOM 更新不等于绘制性能；响应 200 不代表内容正确；stream 后 notFound 可能 HTTP 200，但应展示404并不泄漏正文。
