# Issue 26 后端设计与失败方式

版本前提：当前 main ce35856 后续基线，以主 agent 的 codex/issue-26-collections checkout 为准。实现前已阅读 Issue #26 与当前 AGENTS.md；以下为设计，不代表通过业务验收。

## 领域与数据流

- 首页展示是作品独立布尔属性 `contents.show_in_home`；迁移对既有免费作品填 true、会员作品填 false，保留原首页 public-only 可见状态，既有免费合集章节不批量隐藏。后续独立发布默认 true、首次合集内发布默认 false。未显式给 frontmatter `show_in_home` 的重复发布保留数据库值。付费仍走匿名 preview 投影与逐篇授权。
- 合集介绍、封面、置顶属于合集；章节权限属于 contents，不通过合集上下文授权。已发布目录仅投影元数据，成员验证接口返回 canonical 合集、章节与相邻章节，不返回正文。
- 发布上传 → DB 事务更新正文/关联 → 刷新原与新所属合集 updatedAt → 同事务缓存事件。既有成员保持顺序，新成员按加入顺序追加；发布和 CLI 修改复用全局 publish/GC advisory lock，并对所属合集行按 ID 锁定。
- 封面复用 `MediaStorage`、SHA256 内容寻址、media_assets、`/api/media/:id`、现有引用计数与 GC。先 upload，再事务切换 coverMediaId 与更新时间/缓存；失败保留原封面，旧对象不立即删除。
- CLI `collection create` 管介绍，`cover` / `clear-cover` 管封面，`pin` / `unpin` 管置顶；`content home` / `hide` 管首页。撤回/删除刷新所有旧所属合集与缓存。

## 失败方式与边界

- 迁移不得把既有合集章节批量隐藏；发布缺省不能重置手动设置；一篇多合集仍只有一份首页状态。
- 多内容并发追加必须保持确定顺序；编辑旧篇不得移动序号。撤回/删除不再进入目录；全部合集均刷新更新时间。
- 缺少合集、无效 slug / visibility、未知媒体、非图片封面、上传或事务失败不得部分更新。
- 空目录、首尾邻居、错误稳定 ID、已撤回/移除成员返回可区分的 404；匿名目录允许会员标识但正文和受保护资源保持原授权。
- 公共缓存不能夹带个人权益；付费首页使用既有匿名 preview。封面重用付费正文媒体意味着该指定封面自身公开，其他媒体仍保持权限。
- 更换/清除封面后引用计数精确，GC 只回收零引用且超宽限对象；上传失败保留原值，切换引用与缓存事件同事务。
