# Issue #15 设计与验收前提

- 业务分区：首页仅免费作品；订阅页会员状态、公开/本人问答、付费作品预览；探索仅合集与标签。
- 问答独立 member_questions，comments 显式 question_id 外键与 target_kind，不能伪装作品；user/month 唯一约束负责月度配额并发。
- 会员资格只依据未撤销且有效的 subscription；Asia/Shanghai 自然月；续订连续区间合并展示真实截止。
- 公开问题投影不带未授权回答；私密和隐藏仅本人/管理员；历史提问者可以读取自己的回答。讨论只有有效会员或管理员参与，私密和隐藏关闭讨论。身份相关接口与问答页面全部 private no-store。
- 资料只允许编辑自己，公开展示 DTO 为 username/displayName/avatarUrl，不含 email。头像只允许 ≤2MB 静态 PNG/JPEG/WebP，解码后去元数据重编码为 320px WebP；对象写入 avatars/，媒体GC纳入引用与孤儿宽限清理。
- 通知不含回答或评论预览，只包含事件类型和当前有权限的目标链接。回答+通知同一事务，首次回答通知幂等。
- 验收由主 agent 分派独立子 agent，隔离 DB/存储/邮件；本目录只留设计、实际命令回执和必要证据，不加入固定测试程序。

失败边界：非subscription授予、会员过期/撤销、并发重复提问、上海月底、私密问答越权、跨问答回复、通用回复/locate泄露、活排序翻页失效、CSRF、外站returnTo、危险图片/超大图片、展示名控制字符、并发头像与GC、回答重复通知、私密切换后的旧互动通知权限。
