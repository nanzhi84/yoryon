# 会员权益与页面留白调整

目标：在现有单栏、浅蓝灰色页面内清楚说明会员权益；减小导航到正文的空白。仅本地设计预览，不发布生产。

## 视图边界和排版

- 会员状态/API、认证、兑换、标签、搜索、历史返回的数据流不变。会员状态 → 原有 active/error 分支或权益介绍 → 兑换链接 → 未登录时原有登录提示。
- 删除“读得更深入，交流更直接。”和“使用已有激活码兑换会员权益。”。
- 标题 18px/26px，价格 20px；下方三列权益，用 18px 图标 + 14px/20px 标题 + 12px/20px 说明：专属作品（解锁全部付费内容）、每月提问（每个自然月 1 次）、会员讨论（阅读回答，参与讨论）。说明对应现有会员权限，不新增承诺。
- 权益区域与页面同背景，不加包围卡片、底色、阴影或装饰性边界。标题至权益 16px，权益至原兑换按钮 20px，按钮保持至少 44px 点击高度，会员区到内容 tabs 28px。
- 常规详情/工具页正文顶部统一 20px（原 24/32/48px），共享返回按钮下方 8px（原 16px），不缩小其 44px 点击高度。登录/注册/重置密码的标题下方由 24px 改为 16px。
- 合集详情简介到目录由 32px 改为 20px；资料页标题到内容由 24px 改为 16px。搜索空态、合集空态减少大段竖向空白，404/错误页 96px 改为 32px。
- 首页现有帖子内密度、帖子之间 40px 留白及细分割线、正文继续阅读卡片和评论上方分割线保持。

## 验收边界（先于实现）

使用隔离 DB yoryon_page_redesign_20261013、API 127.0.0.1:4115、Web localhost:3015 和隔离存储，不发邮件、不兑换真实激活码。

独立子 agent 现场检查 595×896 浏览器最终样式与真实路径：三项权益有清晰层级、两句删除、同页面底色、无溢出；CTA → 兑换 → 登录 → 返回；会员作品/问答 tabs 和键盘切换；首页 → 文章 → 返回保留浏览进度；搜索和标签的主要入口；其他受影响页面顶部间距。检查加载/匿名门禁、缺失内容 404、主题对比；无法在现有隔离数据重现的 active 会员、有效兑换、空合集、全局错误明确标 UNVERIFIED，不制造固定 fixture 或测试钩子。

工件包括版本/源文件哈希、实际 pnpm typecheck / pnpm build 回执、独立浏览器截图与报告、命令和隔离数据清理回执；不包含配置值或敏感数据。

## 验收发现后的必要修正（2026-10-14，实现前补充）

独立验收发现既有图集尺寸不稳：首页截图时图像532×299.25，返回后主栏仍532px而图像变297.5×167.34。保存的scrollY恢复后，又因图片布局收缩/滚动锚定改变可见位置。该演示媒体宽高在真实feed元数据均为null，现有shrink-to-fit button及w-descriptor srcset按未知尺寸生成，让图像依赖自然尺寸。证据以acceptance-*阶段测量保留。

修正限定在Markdown图片呈现：按钮以阅读栏宽度布置；有真实width时以其为上限，图像跟随按钮100%宽度和自身比例。只有已知原图width才生成w-descriptor srcset，未知width时使用单一已有图片URL，避免伪造候选像素尺寸。已知width/height继续保留HTML尺寸占位；不猜未知图片的比例、不改图片字节、媒体API或数据库。首次加载缺少元数据的图片仍需读取真实比例，不能声称所有未知图片冷加载无CLS。

新增独立验收边界：同595px主页前后图集宽高稳定、自然浏览点击文章后最终scrollY/目标可见位置保持；图片打开仍居中仅显示图像、Esc关闭；已知尺寸与未知尺寸的CSS路径静态审阅，不新增fixture。必要时另标未知媒体冷加载UNVERIFIED。
