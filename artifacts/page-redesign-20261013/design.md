# 浅蓝头像版落地设计

目标：落实用户确认的第三版视觉，作者头像与浅蓝灰色贯穿站点；首页保持真实内容时间线，订阅介绍区轻巧、可读，沿用既有会员功能。

边界与数据流：RootLayout/CSS 定义品牌与双主题色；SiteHeader 展示原始头像的圆形裁切和既有导航；HomePage 继续读取公开目录并添加通向订阅页的提示；MembershipPanel 只调整会员状态的展示，继续由 /api/me/membership 提供权益，由 /redeem 兑换，不修改 API、数据库结构、授权或定价。媒体继续使用真实内容、既有播放器和访问接口，不把设计图的示意图或波形当成内容数据。

依赖：复用 Next Image 优化本地静态头像，原 JPG 字节保存在 public/images；复用 Tailwind、Radix、Button 与现有图标，不新增依赖。头像在两行导航的品牌组中，账号菜单保留自己的图标，避免混淆作者与读者身份。

编码前明确的失败边界：320px 下品牌与工具横向溢出；价格或兑换按钮截断；头像布局偏移或原图不可辨；浅蓝说明文字对比度不足；深色模式中卡片、文字或按钮失去对比；菜单键盘焦点不可见；未开通、有效会员、状态读取失败和重试分支丢失；兑换登录的 returnTo 改变；真实媒体与文章导航受样式影响。独立 agent 用隔离 API/DB/存储和真实 Browser 现场验收，静态检查与构建仅做各自证据，不新增测试程序。

回滚：恢复本次前端源文件及 ADR-0005 的视觉说明、移除新增作者头像即可；无持久化迁移。
