# 字号与间距设计稿

通过内置image_gen生成，共三张同宽页面概念。只输出设计图，本轮不修改页面代码或正在运行的3015预览。

- home-v2.png：首页信息流最终选稿。first draft因条内空白/正文仍偏大，保留feed-draft-v1.png作为过程；第二次生成收紧标题、正文、标签和互动，扩大外部间距相对于内部的对比。音频/长文/视频用于覆盖不同类型排版，图中展示顺序不是对现有排序的变更。
- article-v1.png：文章详情采用轻分隔与两列同背景上下篇边框卡片；不可用上一篇灰色，可点下一篇蓝色。
- subscription-v1.png：保持两主tab与简洁订阅信息，问答空态无下分割线、无底色或围合边框。

图稿沿用提供截图/当前代码中已有内容与品牌，保留日期在顶部、底部评论/点赞/复制链接转发语义，没有新增App导航、feed作者头像/@或虚构统计。

精确实施参数以design.md为准：信息流标题18/26、正文15/24、辅助12/18；块内8–12px、块间36–40px。图片像素并非浏览器CSS：模型绘制的边距、字重、字体大小及字符形状会有漂移，不能据此声称页面已达到指定CSS值。参考SVG图标与实际文本仍以代码为准。

完整原始提示词在prompts.json，输出尺寸与SHA在manifest.json。独立视觉验收在acceptance.md，仅核对生成稿的层级、用户边界与阅读性，不代替未来实现后的浏览器交互/权限/长标题溢出验收。没有运行typecheck/build，因为本次不修改可执行代码。
