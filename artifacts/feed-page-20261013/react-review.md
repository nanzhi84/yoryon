# React 与边界检查

已按 react-best-practices 技能核对本轮 TSX：列表取数按批统一处理、最多100 ID/请求且并发有界；公开 Feed 仍无身份数据；身份读取 no-store。每批 Context 承载状态，无新依赖，无 N × 接口请求。read 的 AbortController 与代次防止旧读取覆盖当前点赞，写请求具有15秒超时并在卸载时取消；复制反馈计时器与媒体观察器在卸载释放。

每条有独立评论锚点、带 aria-pressed 的点赞按钮、复制链接按钮及键盘焦点。点赞初次取数未完成时禁用，失败可重试；服务端仍为最终权限与计数判定方。复制失败有可选择的只读链接。内容 ID 稳定，不与发布 revision 绑定。

视频首帧只在视口内加载，预览静音且不自动播放；离开或挂载实际播放器时释放预览资源。已有 Video.js 动态加载、失败恢复与播放互斥继续复用；通过实际安装包 CSS 语义变量将 AudioSkin 背景与边框设透明，不推测未知播放器属性。页面宽度沿用 max-w-3xl。

静态检查 pnpm typecheck PASS。构建 pnpm build 在独立源码副本与隔离 API 配置下 PASS；原有 ::highlight(search-hit) 优化器警告仍存在。实际互动与最终可见结果以独立验收报告为准。
