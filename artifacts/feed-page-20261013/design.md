# 信息流实现范围与验收边界

目标：将已确认的单列信息流设计落实到本地页面。外侧画布与阅读区统一背景，媒体入口与长文预览不使用额外背景或围合边框；保留日期在上、标签与内容分区、三项底部动作。媒体使用实际内容，设计稿的风景与波形不冒充发布媒体。

视图职责：FeedTimeline 编排内容，InlineMedia 沿用按需播放器；独立 ContentActions 客户端边界负责评论锚点、点赞反馈和复制永久链接。按每批列表取互动统计，不改变公开 Feed DTO、目录快照或权限裁剪。分享只调用浏览器剪贴板，不发统计请求。

领域职责：content_likes 保存稳定内容 ID 与用户 ID 的唯一关联；内容删除级联清理，用户删除级联清理其赞。GET /api/content-interactions 批量读取已发布内容的评论数、赞数与当前用户状态，private/no-store；PUT/DELETE /api/content-interactions/:id/like 在事务中锁定内容、复用 canAccess 权限，幂等写入/删除，返回实际计数。不引入冗余计数列或通知规则。

数据流：公开时间线 → 客户端批量互动读取 → BFF Cookie/Bearer → Hono → 核心权限与数据库 → 当前用户心形状态。评论跳转既有 /p/:slug#comments。转发复制 location.origin + /p/:slug，成功反馈“链接已复制”，失败提供可选择的链接与重试。

编码前列明失败与边界：游客点赞需登录；无权益/过期/撤销权益拒绝付费点赞；草稿/下架/删除不允许读写互动；重复及并发赞不重复计数，取消不存在的赞保持零；BFF 拒绝跨站写入；批量读取无用户缓存污染；请求失败/超时可重试且旧请求不能覆盖新赞；复制失败可手动复制；键盘可操作；媒体加载失败与停止释放资源，真实媒体不以示意图片替代。

隔离验证：复用之前独立本地预览 DB/FS/API 配置，迁移只作用于 yoryon_page_redesign_20261013；前端在新临时源码副本构建，替换本任务 3015 预览。保留原有其他服务和生产。独立子 agent 现场验收与清理自己的用户/评论/赞/权益，工件留存到此目录，不新增固定测试脚本。
