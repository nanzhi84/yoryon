# 帖子无标题显示

目标：帖子正文直接呈现，不显示“未命名内容”或已有title。长文标题保持。边界：仅Web视图，不改内容、数据库、API和缓存契约。

数据流：现有FeedContentItem/ContentDetail.type → 服务端组件条件渲染 → post日期与正文/互动 → 日期链接到现有详情路由。文章继续h2/h1。帖子详情日期左对齐，不预留长文标题空间；标签/合集非空显示。保留置顶、付费标识与现有权限投影、展开/重试和互动机制，无新增请求或客户端状态。日期入口提供描述性aria-label。

React检查：沿用服务端组件，不增hooks、请求、依赖或共享状态；使用已有TrackClickLink保留无Provider不采集语义，不改预取与隐私边界。无新增固定测试；由独立agent基于真实数据/路径现场验收。可回滚前端部署，不涉及业务数据回滚。
