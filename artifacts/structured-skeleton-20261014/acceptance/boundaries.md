2. 通过真实快速返回/切换不同文章，检查 slug 匹配与旧 Context 不串文。
3. 直接进入文章 URL 时无匹配 Context，应出现安全通用骨架。

6. 结构块数与字符串长度有界，不随长文无上限增长；检查 API 实际响应。
7. Shimmer 动画在结构骨架继续生效；不增加故意等待。
